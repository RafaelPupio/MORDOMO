# Rafael — how to work on this project

Kept deliberately neutral: this brain is public.

- Maintainer and product owner. Solo project.
- Communication: direct, options with a recommendation, one question at a time.
- Cost-conscious by default — running cost is a design constraint, not an afterthought
  (see budget decision in [[log/decisions]]).
- Portfolio audience matters: code and docs here are written to be read by strangers.
- Anything personal or business-sensitive about the maintainer or V1's business does
  not belong in this repo.
